### About me

I've spent 5+ years in enterprise IT and 3+ of them in Security Operations. My day to day is triaging EDR detections, containing hosts and securing **1,000+ endpoints** across North America, LATAM and Europe with CrowdStrike Falcon, Microsoft Defender for Endpoint, Intune and Entra ID.

In this repo space I publish the **tools and playbooks I wish I'd had during real incidents**: PowerShell and Python utilities for triage, identity hygiene and threat intel enrichment.

### What I'm working on

- **M365 / Entra ID audit toolkit:** Stale guest account, privileged role, and licensing hygiene (in progress)
- **Detection Engineering:** Developing targeted KQL hunt queries for Microsoft Defender
